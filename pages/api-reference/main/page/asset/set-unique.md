{% endnote %}

Метод `Asset::setUnique` задает набору постоянный файл объединения. Без метода класс добавляет к имени файла объединения контрольную сумму состава файлов, и каждый состав получает свой файл. С методом имя файла постоянное — префикс набора и суффикс `uniqueID`. Если на странице появились новые файлы, класс дописывает их в этот файл в каталогах `/bitrix/cache/css/` и `/bitrix/cache/js/`.

Метод нужен, когда состав файлов набора меняется от страницы к странице и отдельный файл на каждый состав не нужен.

Сигнатура метода в классе `Bitrix\Main\Page\Asset`:

```php
public function setUnique($setID = '', $uniqueID = '')
```

## Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| setID | `string` | Задает имя набора в верхнем регистре, например `PAGE`. По умолчанию — пустая строка |
| uniqueID | `string` | Задает суффикс. Допустимы латинские буквы, цифры и `_`. По умолчанию — пустая строка |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает `true`. Если имя или суффикс пустые или набора нет, метод возвращает `false`.

## Особенности

Метод не переводит имя набора в верхний регистр. Вызов `setUnique('page', ...)` вернет `false`.

## Примеры

**Пример.** Код задает суффикс набору страницы:

```php
<?php
use Bitrix\Main\Page\Asset;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

$asset = Asset::getInstance();

var_dump($asset->setUnique('page', 'units'), $asset->setUnique('PAGE', 'units'));
```

Код выведет:

```text
bool(false)
bool(true)
```
