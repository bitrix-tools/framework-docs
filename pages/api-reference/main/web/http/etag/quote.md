Метод `Etag::quote` заключает тег сущности в двойные кавычки. По RFC 7232 тег в заголовке `ETag` записывается в кавычках, например `"5d41402abc4b2a76"`.

Сигнатура метода в классе `Bitrix\Main\Web\Http\Etag`:

```php
public static function quote(string $value): string
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| value\* | `string` | Задает тег сущности без префикса `W/`, например хеш содержимого |

## Возвращаемое значение

Метод возвращает тег в двойных кавычках. Если значение уже в кавычках, метод не добавляет вторую пару: `quote('"abc"')` вернет `"abc"`.

## Особенности

- Метод убирает все двойные кавычки в начале и в конце значения и добавляет по одной. Кавычки внутри значения остаются. Пустая строка и `""` дают `""`.
- Пробелы по краям значения метод не убирает: `quote(' abc ')` вернет `" abc "`.
- Метод не проверяет символы значения. Если внутри значения есть кавычка, перевод строки или управляющий символ, заголовок `ETag` получится некорректным. Передавайте значение из допустимых символов, например хеш `md5`.
- Префикс слабого тега `W/` метод не обрабатывает: `quote('W/"abc"')` вернет некорректный тег `"W/"abc"`. Передавайте тег без префикса.

## Примеры

**Пример.** Код выводит тег для заголовка `ETag` и проверяет, что уже заключенное в кавычки значение не меняется.

```php
<?php
use Bitrix\Main\Web\Http\Etag;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Etag::quote(md5('kg')) . PHP_EOL;
echo Etag::quote('"unit-15"') . PHP_EOL;
```

Код выведет `"ebe86682666f2ab3da0843ed3097e4b3"` и `"unit-15"`.
