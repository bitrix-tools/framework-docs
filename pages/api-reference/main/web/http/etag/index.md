## Когда использовать

Класс `Etag` помогает отвечать на условные запросы по RFC 7232. Сервер отдает файл или данные с заголовком `ETag`, а браузер при повторном запросе присылает тот же тег в заголовке `If-None-Match`. Если тег совпал, сервер отвечает кодом `304 Not Modified` без тела.

Метод [quote](quote.md) готовит значение заголовка `ETag`, метод [matches](matches.md) сравнивает теги из `If-None-Match` с тегом ресурса. Оба метода статические. Класс не отправляет заголовки и не меняет код ответа, это делает вызывающий код.

## Методы класса

| Метод | Описание | С версии |
| --- | --- | --- |
| [quote](quote.md) | Заключает тег сущности в двойные кавычки | 26.900.0 |
| [matches](matches.md) | Проверяет, совпадает ли тег ресурса с заголовком `If-None-Match` | 26.900.0 |
