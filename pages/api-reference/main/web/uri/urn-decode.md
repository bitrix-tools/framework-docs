{% note info "" %}

**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Статический метод `Uri::urnDecode` раскодирует строку адреса без разбора на части. Метод раскодирует функцией `rawurldecode` текст между разделителями `://`, `:порт/`, `/`, `?`, `=` и `&`. Метод выполняет обратное преобразование к [urnEncode](urn-encode.md).

Сигнатура метода в классе `Bitrix\Main\Web\Uri`:

```php
public static function urnDecode($str, $charset = false)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| str\* | `string` | Задает закодированный адрес |
| charset | `string` или `false` | Задает кодировку исходного текста. По умолчанию — `false`, без перевода. Подробнее — в разделе «Особенности» |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Возвращаемое значение

Метод возвращает раскодированную строку.

## Особенности

- Метод не меняет `+` на пробел, в отличие от `urldecode`.
- Если `charset` отличается от кодировки сайта, метод перекодирует часть строки до раскодирования. Последовательности `%XX` состоят из латиницы, поэтому перекодировка на них не влияет, и раскодированный текст остается в исходной кодировке. Если нужна кодировка сайта, перекодируйте результат отдельно.
- В более ранних версиях, например 26.150.0, значение `charset` по умолчанию — `'UTF-8'`. На сайте в UTF-8 результат тот же.

## Примеры

**Пример.** Код раскодирует путь к файлу:

```php
<?php
use Bitrix\Main\Web\Uri;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Uri::urnDecode('/docs/report%202025.pdf?lang=ru');
```

Код выведет `/docs/report 2025.pdf?lang=ru`.
