## Когда использовать

Класс `SqlExpression` хранит шаблон SQL-фрагмента и значения для его плейсхолдеров. Метод `compile` подставляет значения в шаблон и экранирует их через `SqlHelper` соединения.

Объект `SqlExpression` подходит там, где нужен SQL-фрагмент, а не скалярное значение. ORM принимает объект как значение поля, например `CNT + 1`. Объект можно передать в `Connection::query` вместо строки запроса, метод приводит его к строке.

Чтобы экранировать одно значение без шаблона, используйте методы `SqlHelper::forSql` и `SqlHelper::quote`.
