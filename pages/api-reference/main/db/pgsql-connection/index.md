## Когда использовать

Класс `PgsqlConnection` — реализация [Connection](../connection/index.md) для PostgreSQL. Объект возвращает `Application::getConnection()`, если в `.settings.php` для соединения указан `className` со значением `\Bitrix\Main\DB\PgsqlConnection`.

Класс [Connection](../connection/index.md) описывает методы, которые вызывает код приложения. Страницы методов `Connection` описывают поведение PostgreSQL в таблицах реализаций.

Методы `isTableExists` и `getTableFields` ищут таблицы в схеме `public`. Строки результатов приходят с ключами в верхнем регистре.

## Методы класса

Методов ниже нет в классе `Connection`.

| Метод | Описание | С версии |

## Наследование

Класс наследует [Connection](../connection/index.md).

### Реализация методов базового класса

| Метод | Особенность реализации |
| --- | --- |
| [add](../connection/add.md) | Если `identity` не `null`, а значение автоинкрементной колонки не передано или передано объектом `SqlExpression`, добавляет строку с `RETURNING` и возвращает новое значение целым числом. Иначе возвращает переданное значение колонки или `null` |
| [getInsertedId](../connection/get-inserted-id.md) | Выполняет `SELECT bx_lastval()`. При ошибке запроса возвращает `0` |
| [getAffectedRowsCount](../connection/get-affected-rows-count.md) | Возвращает `pg_affected_rows` для результата последнего запроса |
| [isTableExists](../connection/is-table-exists.md) | Ищет таблицу с точным именем в схеме `public` |
| [isIndexExists](../connection/is-index-exists.md) | Вызывает `getIndexName` в нестрогом режиме, как в MySQL |
| [getIndexName](../connection/get-index-name.md) | Сравнивает имена колонок без учета регистра. Для индекса с выражением берет колонки из выражения. Имя таблицы не приводит к нижнему регистру и ищет таблицу во всех схемах. Для несуществующей таблицы возвращает `null` |
| [getTableFields](../connection/get-table-fields.md) | Читает `information_schema.columns` для схемы `public`. Приводит имена колонок к верхнему регистру. Пустой результат не кеширует |
| [createTable](../connection/create-table.md) | Для автоинкремента создает колонку `GENERATED BY DEFAULT AS IDENTITY` |
| [createIndex](../connection/create-index.md) | Строит запрос с `IF NOT EXISTS`. Для `INDEX_FULLTEXT` создает индекс `GIN` по `to_tsvector('english', ...)` |
| [renameTable](../connection/rename-table.md) | Выполняет `ALTER TABLE ... RENAME TO` |
| [dropTable](../connection/drop-table.md) | Выполняет `DROP TABLE` и очищает кеш описания колонок, как в MySQL |
| [startTransaction](../connection/start-transaction.md) | Открывает транзакцию или создает точку сохранения, как в MySQL |
| [commitTransaction](../connection/commit-transaction.md) | Выполняет `COMMIT` только на внешнем уровне, как в MySQL |
| [rollbackTransaction](../connection/rollback-transaction.md) | Во вложенной транзакции откатывает до точки сохранения без исключения |
| [lock](../connection/lock.md) | Вызывает функцию `bx_get_lock`. Имя блокировки — число `crc32`. Возвращает `true`, если функция вернула `0` |
| [unlock](../connection/unlock.md) | Вызывает функцию `bx_release_lock`. Возвращает `true`, если функция вернула `0` |
| [getType](../connection/get-type.md) | Возвращает `pgsql` |
| [getVersion](../connection/get-version.md) | Возвращает массив `[версия, null]`, где версия — два числа через точку, например `16.4` |
| [getErrorMessage](../connection/get-error-message.md) | Возвращает текст функции `pg_last_error` |
| [getErrorCode](../connection/get-error-code.md) | Возвращает код SQLSTATE из сообщения об ошибке строкой |

### Унаследованные методы

Остальные методы работают как в классе [Connection](../connection/index.md#методы-класса). Метод `getMaxAllowedPacket` работает как в классе `Bitrix\Main\Data\Connection` и возвращает `PHP_INT_MAX`.
