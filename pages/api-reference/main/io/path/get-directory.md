{% endnote %}

Метод `Path::getDirectory` возвращает часть пути до последней косой черты `/`. Для пути к файлу это путь к каталогу файла.

Сигнатура метода в классе `Bitrix\Main\IO\Path`:

```php
public static function getDirectory($path)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| path\* | `string` | Задает путь |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает строку. Для нормализованного пути результат не содержит завершающей косой черты.

Метод отрезает от пути результат [getName](get-name.md) и одну косую черту, поэтому крайние случаи отличаются от функции PHP `dirname`:

- для файла в корне, например `/kg.txt`, метод возвращает пустую строку, а не `/`,
- для пути без `/`, например `kg.txt`, метод возвращает пустую строку,
- для пути с завершающей `/`, например `/upload/units/`, метод возвращает `/upload/units`.

## Примеры

**Пример.** Код выводит каталог файла:

```php
<?php
use Bitrix\Main\IO\Path;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Path::getDirectory('/upload/units/kg.txt');
```

Код выведет `/upload/units`.
