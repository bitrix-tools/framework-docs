---

{% note info "" %}

**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Метод `Path::getName` возвращает часть пути после последней косой черты `/`. Для пути к файлу это имя файла с расширением. Метод работает как функция PHP `basename`, но считает разделителем только `/` и учитывает многобайтовые символы.

Сигнатура метода в классе `Bitrix\Main\IO\Path`:

```php
public static function getName($path)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| path\* | `string` | Задает путь |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает строку. Если в пути нет `/`, метод возвращает путь целиком. Если путь заканчивается на `/`, метод возвращает пустую строку.

Метод ищет `/` в строке UTF-8. Для строки в другой кодировке метод возвращает путь целиком.

## Примеры

**Пример.** Код выводит имя файла из пути:

```php
<?php
use Bitrix\Main\IO\Path;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Path::getName('/upload/units/kg.txt');
```

Код выведет `kg.txt`.
