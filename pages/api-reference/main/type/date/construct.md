Конструктор `Date::__construct` создает дату из строки. Без строки конструктор создает текущую дату. Время объекта всегда `00:00:00` в часовом поясе сервера.

Сигнатура метода в классе `Bitrix\Main\Type\Date`:

```php
public function __construct($date = null, $format = null)
```

## Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| date | `?string` | Задает дату строкой. Если передать `null` или пустую строку, конструктор создает текущую дату. По умолчанию — `null` |
| format | `?string` | Задает маску PHP, например `'Y-m-d'`. Если передать `null`, конструктор берет формат даты из региональных настроек методом [getFormat](get-format.md). По умолчанию — `null` |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Исключения

| Исключение | Когда возникает |
| --- | --- |
| `Bitrix\Main\ObjectException` | Конструктор не смог разобрать строку. Сообщение исключения — `Incorrect date: ` и переданная строка |

## Особенности

Конструктор разбирает строку функцией `date_parse_from_format` и не требует точного совпадения с форматом. Конструктор выбрасывает исключение, только если при разборе больше одной ошибки, кроме лишних или недостающих символов. Поэтому конструктор принимает и исправляет такие строки:

- конструктор пропускает лишние символы в конце строки, например время в строке `'2026-01-15 13:45'` для формата `'Y-m-d'`,
- если в строке нет месяца или дня, конструктор ставит `1`, например строка `'2026-01'` для формата `'Y-m-d'` дает 1 января 2026 года,
- конструктор переносит несуществующий день на следующий месяц, например `'31.02.2025'` для формата `'d.m.Y'` дает 3 марта 2025 года.

Конструктор принимает маску в нотации PHP. Формат региональных настроек, например `'DD.MM.YYYY'`, переведите в маску методом [convertFormatToPhp](convert-format-to-php.md).

## Примеры

**Пример.** Код создает дату из строки по маске PHP и выводит ее с временем:

```php
<?php
use Bitrix\Main\Type\Date;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

$date = new Date('2026-01-15', 'Y-m-d');

echo $date->format('d.m.Y H:i:s');
```

Код выведет `15.01.2026 00:00:00`.

**Пример.** Код разбирает строку в формате региональных настроек и обрабатывает ошибку формата:

```php
<?php
use Bitrix\Main\ObjectException;
use Bitrix\Main\Type\Date;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

try
{
    $date = new Date('15.01.2026');
    echo $date->format('Y-m-d');
}
catch (ObjectException $exception)
{
    echo 'Неверная дата';
}
```

При формате даты `DD.MM.YYYY` в региональных настройках код выведет `2026-01-15`.
