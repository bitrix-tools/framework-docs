## Когда использовать

Класс `Date` хранит дату без времени. ORM возвращает объект `Date` для полей с датой и принимает его при записи. Объект хранит значение в объекте стандартного класса PHP `\DateTime`. Конструктор устанавливает время `00:00:00` в часовом поясе сервера.

Конструктор и метод [toString](to-string.md) работают с форматом даты из региональных настроек, если формат не передан. Метод [format](format.md) выводит дату по маске PHP, метод [add](add.md) сдвигает дату на интервал.

Для даты со временем и часовыми поясами используйте наследника [DateTime](../date-time/index.md). В классическом API с датами работают функции `MakeTimeStamp`, `ConvertTimeStamp`, `AddToTimeStamp` и `CheckDateTime`. Эти функции принимают и возвращают дату строкой или меткой времени Unix.

Подробнее — в статье [Дата и время](../../../../advanced/datetime.md).
