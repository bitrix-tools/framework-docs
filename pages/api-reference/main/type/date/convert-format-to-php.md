**Модуль:** `main` — подключать отдельно не нужно

**Доступно с версии:** 14.0.18

{% endnote %}

Метод `Date::convertFormatToPhp` переводит формат даты из нотации региональных настроек, например `DD.MM.YYYY HH:MI:SS`, в маску PHP. Классический метод `CDatabase::DateFormatToPHP` вызывает этот метод.

Сигнатура метода в классе `Bitrix\Main\Type\Date`:

```php
public static function convertFormatToPhp($format)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| format\* | `string` | Задает формат в нотации региональных настроек |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает маску PHP. Метод заменяет обозначения по таблице, остальные символы оставляет без изменений.

| Обозначение | Маска PHP | Значение |
| --- | --- | --- |
| `YYYY` | `Y` | Год из четырех цифр |
| `MMMM` | `F` | Полное название месяца на английском |
| `MM` | `m` | Месяц с ведущим нулем |
| `DD` | `d` | День с ведущим нулем |
| `TT` | `A` | `AM` или `PM` |
| `T` | `a` | `am` или `pm` |
| `MI` | `i` | Минуты с ведущим нулем |
| `SS` | `s` | Секунды с ведущим нулем |
| `HH` | `H` | Час от `00` до `23` |
| `H` | `h` | Час от `01` до `12` |
| `GG` | `G` | Час от `0` до `23` без ведущего нуля |
| `G` | `g` | Час от `1` до `12` без ведущего нуля |

Одиночную `H` метод переводит в `h`, только если в формате нет `HH`. Одиночную `G` — только если нет `GG`.

## Примеры

**Пример.** Код переводит в маски PHP два формата с 24-часовым и 12-часовым временем:

```php
<?php
use Bitrix\Main\Type\Date;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Date::convertFormatToPhp('DD.MM.YYYY HH:MI:SS') . ' | ' . Date::convertFormatToPhp('MM/DD/YYYY H:MI:SS T');
```

Код выведет `d.m.Y H:i:s | m/d/Y h:i:s a`.
