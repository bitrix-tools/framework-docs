**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Метод `Date::setDate` устанавливает год, месяц и день и возвращает тот же объект. Время объекта метод не меняет.

Сигнатура метода в классе `Bitrix\Main\Type\Date`:

```php
public function setDate($year, $month, $day)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| year\* | `int` | Задает год |
| month\* | `int` | Задает месяц от `1` до `12` |
| day\* | `int` | Задает день месяца |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Возвращаемое значение

Метод возвращает текущий объект.

Метод передает значения в метод `setDate` стандартного класса `\DateTime` и не проверяет их. Значение за пределами месяца или года PHP переносит на следующий период. Например, 30 февраля 2026 года становится 2 марта.

## Примеры

**Пример.** Код устанавливает первое число месяца для текущей даты:

```php
<?php
use Bitrix\Main\Type\Date;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

$date = new Date();
$date->setDate((int)$date->format('Y'), (int)$date->format('n'), 1);

echo $date->format('d');
```

Код выведет `01`.
