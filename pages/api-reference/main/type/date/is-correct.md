{% note info "" %}

**Модуль:** `main` — подключать отдельно не нужно

**Доступно с версии:** 14.0.18

{% endnote %}

Метод `Date::isCorrect` проверяет, получится ли создать объект из строки. Метод создает объект конструктором и перехватывает исключение `Bitrix\Main\ObjectException`.

Аналог в классическом API — функция `CheckDateTime`. Она принимает формат в нотации региональных настроек, а не маску PHP.

Сигнатура метода в классе `Bitrix\Main\Type\Date`:

```php
public static function isCorrect($time, $format = null)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| time\* | `string` | Задает строку с датой |
| format | `?string` | Задает маску PHP, например `'Y-m-d'`. Если передать `null`, метод берет формат из региональных настроек. По умолчанию — `null` |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Возвращаемое значение

Метод возвращает `true`, если конструктор создал объект, и `false`, если конструктор выбросил исключение. Для пустого значения, в том числе строки `'0'`, метод возвращает `false`.

Вызов `DateTime::isCorrect` создает объект `DateTime` и по умолчанию проверяет строку по формату даты и времени.

## Особенности

Метод проверяет только, разобрал ли конструктор строку. Поэтому метод возвращает `true` и для строк, которые конструктор исправляет, например:

- для несуществующего дня, например `'31.02.2025'` с маской `'d.m.Y'`,
- для строки с лишними символами в конце, например `'2026-01-15 13:45'` с маской `'Y-m-d'`,
- для строки без дня, например `'2026-01'` с маской `'Y-m-d'`.

Чтобы отклонить несуществующую дату, сравните строку с результатом разбора, как в примере ниже.

## Примеры

**Пример.** Код проверяет три строки и отдельно отклоняет несуществующую дату:

```php
<?php
use Bitrix\Main\Type\Date;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

foreach (['15.01.2026', '31.02.2026', 'today'] as $value)
{
    $isCorrect = Date::isCorrect($value, 'd.m.Y');
    $isExact = $isCorrect && (new Date($value, 'd.m.Y'))->format('d.m.Y') === $value;

    echo $value . ': ' . var_export($isCorrect, true) . ', ' . var_export($isExact, true) . PHP_EOL;
}
```

Код выведет:

```text
15.01.2026: true, true
31.02.2026: true, false
today: false, false
```
