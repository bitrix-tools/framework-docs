Метод `DateTime::toUserTime` переводит время объекта во время текущего пользователя и возвращает тот же объект. Метод меняет текущий объект. Чтобы сохранить исходное время, вызывайте метод у копии, полученной оператором `clone`.

Сигнатура метода в классе `Bitrix\Main\Type\DateTime`:

```php
public function toUserTime()
```

## Возвращаемое значение

Метод возвращает текущий объект.

Метод переводит объект в часовой пояс сервера методом [setDefaultTimeZone](set-default-time-zone.md). Затем метод сдвигает время на разницу между поясом пользователя и поясом сервера, которую возвращает `CTimeZone::GetOffset`. Часовой пояс объекта остается поясом сервера, поэтому метка Unix после сдвига меняется.

Метод берет пояс пользователя в таком порядке:

1. Пояс из профиля пользователя.
2. Пояс из cookie браузера, если в профиле пояса нет и включено автоопределение. Автоопределение задает поле профиля, а если оно пустое — параметр `auto_time_zone` главного модуля.
3. Пояс из параметра `default_time_zone` главного модуля. Без объекта `$USER` метод сразу берет этот параметр.

Метод не сдвигает время, если:

- на сайте выключены часовые пояса,
- код временно отключил часовые пояса методом `CTimeZone::Disable`,
- пояс пользователя совпадает с поясом сервера,
- у пользователя нет пояса и параметр `default_time_zone` пустой,
- имя пояса в профиле или cookie некорректное.

## Примеры

**Пример.** Код выводит время сервера и время пользователя для одного момента:

```php
<?php
use Bitrix\Main\Type\DateTime;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

$serverTime = new DateTime('2026-01-15 12:00:00', 'Y-m-d H:i:s');
$userTime = (clone $serverTime)->toUserTime();

echo $serverTime->format('H:i') . ' ' . $userTime->format('H:i');
```

Для пользователя, пояс которого на три часа восточнее пояса сервера, код выведет `12:00 15:00`. Если часовые пояса выключены, код выведет `12:00 12:00`.
