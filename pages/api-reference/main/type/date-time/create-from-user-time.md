description: Метод DateTime::createFromUserTime разбирает строку с временем пользователя в формате региональных настроек и возвращает время сервера.
---

{% note info "" %}

**Модуль:** `main` — подключать отдельно не нужно

**Доступно с версии:** 14.0.18

{% endnote %}

Метод `DateTime::createFromUserTime` создает объект из строки, которую ввел пользователь в своем часовом поясе. Метод возвращает время сервера. Для этого метод сдвигает время на разницу между поясом пользователя и поясом сервера. Метод [toUserTime](to-user-time.md) выполняет обратный перевод.

Сигнатура метода в классе `Bitrix\Main\Type\DateTime`:

```php
public static function createFromUserTime($timeString)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| timeString\* | `string` | Задает дату со временем или только дату в формате региональных настроек сайта |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает объект `DateTime` со временем сервера.

Метод разбирает строку по формату даты и времени. Если конструктор не разобрал строку по этому формату, метод разбирает ее по формату даты и ставит время `00:00:00`.

Метод выбирает пояс пользователя так же, как [toUserTime](to-user-time.md). Метод не сдвигает время, если на сайте выключены часовые пояса, код отключил их методом `CTimeZone::Disable` или смещение пояса пользователя равно нулю.

## Исключения

| Исключение | Когда возникает |
| --- | --- |
| `Bitrix\Main\ObjectException` | Строка не подходит ни под формат даты и времени, ни под формат даты |

## Примеры

**Пример.** Код переводит время из формы во время сервера:

```php
<?php
use Bitrix\Main\ObjectException;
use Bitrix\Main\Type\DateTime;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

try
{
    $serverTime = DateTime::createFromUserTime('15.01.2026 18:00:00');
    echo $serverTime->format('Y-m-d H:i:s');
}
catch (ObjectException $exception)
{
    echo 'Неверная дата';
}
```

При формате `DD.MM.YYYY HH:MI:SS` в региональных настройках и поясе пользователя на три часа восточнее пояса сервера код выведет `2026-01-15 15:00:00`. Если часовые пояса выключены, код выведет `2026-01-15 18:00:00`.
