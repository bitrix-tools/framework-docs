**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Метод `DateTime::setTime` устанавливает время объекта и возвращает тот же объект. Метод не меняет часовой пояс, а дату меняет только при переполнении значений.

Сигнатура метода в классе `Bitrix\Main\Type\DateTime`:

```php
public function setTime($hour, $minute, $second = 0, $microseconds = 0)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| hour\* | `int` | Задает часы |
| minute\* | `int` | Задает минуты |
| second | `int` | Задает секунды. По умолчанию — `0` |
| microseconds | `int` | Задает микросекунды. По умолчанию — `0` |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Возвращаемое значение

Метод возвращает текущий объект.

Метод передает значения в метод `setTime` стандартного класса `\DateTime` и не проверяет их. Лишние часы и минуты переходят на следующий период. Например, `setTime(25, 70)` для 15 января дает 16 января 02:10.

## Примеры

**Пример.** Код устанавливает время начала рабочего дня для даты из строки:

```php
<?php
use Bitrix\Main\Type\DateTime;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

$start = new DateTime('2026-01-15', 'Y-m-d');
$start->setTime(9, 30);

echo $start->format('Y-m-d H:i:s');
```

Код выведет `2026-01-15 09:30:00`.
