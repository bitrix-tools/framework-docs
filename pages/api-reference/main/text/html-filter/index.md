## Когда использовать

Класс `HtmlFilter` экранирует специальные символы HTML в строке перед выводом на страницу. Так браузер не выполняет данные пользователя как HTML-код. Аналог в классическом API — функция `htmlspecialcharsbx` с теми же параметрами и результатом.
