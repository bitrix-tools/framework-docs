## Когда использовать

Класс `Emoji` заменяет четырехбайтовые символы UTF-8, например эмодзи, текстовыми кодами вида `:f09f9880:` и восстанавливает их. Так текст с эмодзи можно сохранить в колонку, кодировка которой не принимает четырехбайтовые символы. Все методы класса статические.

Методы [getSaveModificator](get-save-modificator.md) и [getFetchModificator](get-fetch-modificator.md) возвращают обработчики сохранения и выборки для полей ORM.

## Методы класса

| Метод | Описание | С версии |
| --- | --- | --- |
| [encode](encode.md) | Заменяет четырехбайтовые символы текстовыми кодами | |
| [decode](decode.md) | Восстанавливает символы из текстовых кодов | |
| [replace](replace.md) | Заменяет четырехбайтовые символы результатом переданной функции | |
| [getSaveModificator](get-save-modificator.md) | Возвращает массив обработчиков сохранения для поля ORM | |
| [getFetchModificator](get-fetch-modificator.md) | Возвращает массив обработчиков выборки для поля ORM | |
