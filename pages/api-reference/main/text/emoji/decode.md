{% endnote %}

Метод `Emoji::decode` заменяет текстовые коды, которые создал [encode](encode.md), исходными символами.

Сигнатура метода в классе `Bitrix\Main\Text\Emoji`:

```php
public static function decode($text)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| text\* | `string` | Задает текст с кодами |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает строку `string`.

Метод ищет коды из восьми шестнадцатеричных цифр между двоеточиями, регистр цифр не важен. Код, байты которого не образуют четырехбайтовый символ UTF-8, метод оставляет без изменений. Например, код `:12345678:` останется в тексте.

## Примеры

**Пример.** Код восстанавливает эмодзи из кода и оставляет без изменений код, который не соответствует эмодзи:

```php
<?php
use Bitrix\Main\Text\Emoji;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Emoji::decode('Готово :f09f9880: :12345678:');
```

Код выведет `Готово 😀 :12345678:`.
