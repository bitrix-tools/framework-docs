**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Метод `Emoji::encode` заменяет каждый четырехбайтовый символ UTF-8 текстовым кодом. Код состоит из шестнадцатеричного представления байтов символа между двоеточиями, например `:f09f9880:`. Метод [decode](decode.md) восстанавливает символы.

Сигнатура метода в классе `Bitrix\Main\Text\Emoji`:

```php
public static function encode($text)
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| text\* | `string` | Задает текст |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает строку `string`. Символы короче четырех байтов, в том числе кириллицу, метод не меняет.

## Примеры

**Пример.** Код кодирует текст с эмодзи:

```php
<?php
use Bitrix\Main\Text\Emoji;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Emoji::encode("Готово \u{1F600}");
```

Код выведет `Готово :f09f9880:`.
