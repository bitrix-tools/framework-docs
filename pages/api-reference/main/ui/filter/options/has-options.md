**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Статический метод `Options::hasOptions` проверяет, есть ли у текущего пользователя сохраненные настройки фильтра. Метод нужен, например, чтобы задать пресеты по умолчанию только при первом открытии страницы.

Сигнатура метода в классе `Bitrix\Main\UI\Filter\Options`:

```php
public static function hasOptions($filterId): bool
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| filterId\* | `string` | Задает идентификатор фильтра |

Тип в таблице описывает назначение аргумента. Сигнатура PHP не объявляет его.

## Возвращаемое значение

Метод возвращает `true`, если в настройках пользователя категории `main.ui.filter` есть запись фильтра, иначе `false`.

## Особенности

Метод не видит настройки гостя в локальном хранилище сессии и общие настройки для всех пользователей.

## Примеры

**Пример.** Код проверяет настройки фильтра, который пользователь еще не открывал:

```php
<?php
use Bitrix\Main\UI\Filter\Options;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

var_dump(Options::hasOptions('units_filter'));
```

Код выведет `bool(false)`.
