## Когда использовать

Класс `CurrentUser` возвращает данные текущего пользователя — идентификатор, логин, имя, группы и права. Метод [get](get.md) возвращает объект класса. В контроллере метод `getCurrentUser` возвращает объект текущего пользователя, а действие контроллера получает объект, если объявит параметр с типом `CurrentUser`.

Класс читает данные из глобального объекта `$USER` класса `CUser`. Если `$USER` не объект `CUser`, методы возвращают `null`, пустой массив, пустую строку или `false`. Класс финальный, конструктор защищенный.

Аналог в классическом API — глобальный объект `$USER`.

Подробнее — в разделе «Получить текущего пользователя» статьи [Контроллеры](../../../../framework/controllers.md).
