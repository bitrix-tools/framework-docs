{% note info "" %}

**Модуль:** `main` — подключать отдельно не нужно

{% endnote %}

Метод `Loc::getPluralForm` возвращает номер формы множественного числа для числа. Номер становится окончанием кода фразы в [getMessagePlural](get-message-plural.md).

Сигнатура метода в классе `Bitrix\Main\Localization\Loc`:

```php
public static function getPluralForm($value, $language = null): int
```

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

| Параметр | Тип | Описание |
| --- | --- | --- |
| value\* | `int` | Задает число. Метод приводит его к целому и берет модуль |
| language | `string`, `null` | Задает код языка. По умолчанию — `null`, текущий язык |

Типы в таблице описывают назначение аргументов. Сигнатура PHP не объявляет их.

## Возвращаемое значение

Метод возвращает номер формы от `0` до `4`. Правила зависят от языка.

| Языки | Формы |
| --- | --- |
| `ru`, `ua` | `0` — числа, которые оканчиваются на 1, кроме оканчивающихся на 11. `1` — числа, которые оканчиваются на 2–4, кроме оканчивающихся на 12–14. `2` — остальные числа |
| `pl` | `0` — только 1. `1` — числа, которые оканчиваются на 2–4, кроме оканчивающихся на 12–14. `2` — остальные числа |
| `de`, `en`, `hi`, `it`, `la` | `0` — только 1. `1` — остальные числа, в том числе 0 |
| `br`, `fr`, `tr` | `0` — 0 и 1. `1` — числа больше 1 |
| `ar` | `0` — 0. `1` — 1 и числа, кратные 100. `2` — 2. `3` — остаток от деления на 100 от 3 до 10. `4` — остальные числа |
| `id`, `ja`, `ms`, `sc`, `tc`, `th`, `vn` | Всегда `0` |
| Другие языки | Всегда `1` |

## Примеры

**Пример.** Код выводит номера форм для чисел 1, 3, 11 и 25 на русском языке:

```php
<?php
use Bitrix\Main\Localization\Loc;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

foreach ([1, 3, 11, 25] as $value)
{
    echo $value . ' — ' . Loc::getPluralForm($value, 'ru') . PHP_EOL;
}
```

Код выведет формы `0`, `1`, `2` и `2`.
