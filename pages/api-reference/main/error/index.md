## Когда использовать

Класс `Error` описывает одну ошибку: сообщение, код и произвольные дополнительные данные. Объекты `Error` возвращают методы, которые сообщают об ошибках через результат, а не через исключение. Например, результат ORM и контроллеры складывают ошибки в коллекцию [ErrorCollection](../error-collection/index.md).

Сообщение может быть строкой или объектом `LocalizableMessageInterface`, который переводит фразу на язык в момент вывода.

## Методы класса

| Метод | Описание | С версии |
| --- | --- | --- |
| [__construct](construct.md) | Создает ошибку из сообщения, кода и дополнительных данных | |
| [createFromThrowable](create-from-throwable.md) | Создает ошибку из исключения | |
| [getMessage](get-message.md) | Возвращает текст сообщения | 15.5.9 |
| [getCode](get-code.md) | Возвращает код ошибки | 15.5.9 |
| [getLocalizableMessage](get-localizable-message.md) | Возвращает переводимое сообщение, если ошибку создали с ним | |
| [getCustomData](get-custom-data.md) | Возвращает дополнительные данные | |
| [jsonSerialize](json-serialize.md) | Возвращает массив для кодирования в JSON | |

Класс реализует интерфейс `JsonSerializable`. При приведении к строке объект возвращает текст сообщения. После `unserialize` объект остается пустым, данные ошибки не восстанавливаются.
