{% note info "" %}

**Пространство имен:** `Bitrix\Main\Config`

**Модуль:** `main` — подключать отдельно не нужно. Для выполнения примеров нужен пролог сайта.

{% endnote %}

## Когда использовать

Класс `Option` хранит параметры модулей в базе данных, общие для всех сайтов или отдельные для конкретного сайта. Его методы вызывают статически, без создания объекта.

Метод `get` возвращает параметр с учетом общих значений и значений по умолчанию. Метод `getRealValue` проверяет, сохранен ли параметр именно для выбранного сайта или в общих параметрах. Метод `getForModule` возвращает набор сохраненных параметров модуля.

{% note warning "" %}

Класс `COption` помечен устаревшим. Его методы продолжают работать через `Option`. Для нового кода используйте `Option`.

{% endnote %}
