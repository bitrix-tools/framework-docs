## Когда использовать

Класс `Random` генерирует случайные числа, строки и байты для паролей, токенов, кодов подтверждения и ключей. Источник случайности — криптографический генератор OpenSSL или `/dev/urandom`, если они доступны. Запасной источник описан на странице [getBytes](get-bytes.md). Все методы класса статические.

Аналог в классическом API — функция `randString`, она вызывает методы этого класса.

## Методы класса

| Метод | Описание | С версии |
| --- | --- | --- |
| [getInt](get-int.md) | Возвращает случайное целое число в заданном диапазоне | |
| [getString](get-string.md) | Возвращает случайную строку из цифр и латинских букв | |
| [getStringByAlphabet](get-string-by-alphabet.md) | Возвращает случайную строку из наборов символов по маске | |
| [getStringByCharsets](get-string-by-charsets.md) | Возвращает случайную строку из заданных символов | |
| [getStringByArray](get-string-by-array.md) | Возвращает случайную строку, в которой есть символы из каждого набора | |
| [getBytes](get-bytes.md) | Возвращает строку случайных байтов | |

## Константы

| Константа | Значение | Описание |
| --- | --- | --- |
| `ALPHABET_NUM` | `1` | Цифры `0123456789` |
| `ALPHABET_ALPHALOWER` | `2` | Строчные латинские буквы |
| `ALPHABET_ALPHAUPPER` | `4` | Прописные латинские буквы |
| `ALPHABET_SPECIAL` | `8` | Специальные символы `,.#!*%$:-^@{}[]()_+=<>?&;` |
| `ALPHABET_ALL` | `15` | Все наборы символов |
| `RANDOM_BLOCK_LENGTH` | `64` | Длина блока в байтах для запасного источника случайности |

Константы наборов объединяют оператором `|`, например `Random::ALPHABET_NUM | Random::ALPHABET_ALPHAUPPER`.
