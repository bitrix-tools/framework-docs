**Доступно с версии:** 14.0.0

{% endnote %}

Метод `Context::getSite` возвращает идентификатор текущего сайта, например `s1`. Аналог в классическом API — константа `SITE_ID`.

Сигнатура метода в классе `Bitrix\Main\Context`:

```php
public function getSite()
```

## Возвращаемое значение

Метод возвращает строку с идентификатором сайта или `null`, если сайт не задан.

В публичной части ядро определяет сайт по домену и пути страницы. Если до подключения ядра задана константа `SITE_ID` или `LANG`, ядро берет сайт из нее, в том числе в административном разделе. Для несуществующего сайта из константы ядро выбрасывает `Bitrix\Main\SystemException`.

Без этих констант в административном разделе ядро сайт не задает, и метод возвращает `null`. В административном разделе константа `SITE_ID` содержит идентификатор языка.

## Примеры

**Пример.** Код выводит идентификатор сайта или сообщение для административного раздела:

```php
<?php
use Bitrix\Main\Context;

require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

echo Context::getCurrent()->getSite() ?? 'No site';
```

На сайте `s1` код выведет `s1`.
