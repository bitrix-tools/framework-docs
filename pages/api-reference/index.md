Справочник описывает классы и методы Bitrix Framework. На странице метода есть сигнатура, параметры, возвращаемое значение, исключения и пример кода.

Первая версия охватывает 73 класса [главного модуля main](main/index.md), которые другие модули используют чаще всего. Это приложение и контекст, конфигурация, база данных и ORM, события, контроллеры, маршрутизация, HTTP, кеш и даты. Остальные классы `main` и других модулей добавим позже.

Если не нашли нужный класс, заметили ошибку или хотите предложить, какие классы описать следующими, напишите нам через [обратную связь](../../feedback.md).
