`ui.a11y` — JavaScript-расширение Bitrix Framework для сценариев доступности в интерфейсе. Оно помогает управлять фокусом, определять способ ввода, проверять интерактивность DOM-элементов и передавать сообщения скринридеру через live region.

Используйте расширение, когда компонент открывает модальное окно, удаляет активный элемент из DOM, строит клавиатурную навигацию внутри меню или должен сообщить пользователю об изменении интерфейса без перемещения фокуса.

## Подключить расширение

Если вы подключаете JavaScript API из PHP, загрузите расширение `ui.a11y`.

```php
\Bitrix\Main\UI\Extension::load('ui.a11y');
```

В модульном JavaScript импортируйте нужные классы из `ui.a11y`.

```js
import { FocusMonitor, FocusTrap, FocusZone, LiveAnnouncer } from 'ui.a11y';
```
